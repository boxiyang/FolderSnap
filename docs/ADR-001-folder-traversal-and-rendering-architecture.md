# ADR-001: 文件夹递归遍历、渲染呈现与批量截图导出架构决策

- **状态**: Accepted (已采纳)
- **日期**: 2026-09-15
- **决策者**: 用户需求 / 架构对齐

---

## 1. 背景与诉求 (Context)
用户需要一个纯前端的 HTML/JS Web 应用，能够：
1. 选取本地文件夹，自动递归遍历所有子文件夹及内部文件；
2. 将各个子文件夹的文件列表优雅、美观地截图出来（支持按文件夹切分子截图，也支持合成全景大图）；
3. 视觉风格要求达到现代精致卡片风（macOS 磨砂窗口质感、统计信息、彩色文件类型标记等）；
4. 支持过滤冗余系统/开发目录（如 `.git`, `node_modules` 等），并支持批量打包为 ZIP 导出。

## 2. 决策要点 (Decisions)

### 2.1 文件夹选取与遍历策略 (Folder Traversal Strategy)
- **决策**: 双轨制并提供主动模式切换（默认极速模式）。
  - **⚡ 极速选择模式 (`<input type="file" webkitdirectory>`，默认首选)**:
    - 解决 Windows 平台下 Chromium `showDirectoryPicker()` 需进行跨进程安全校验及 Windows Shell 扫描 OneDrive/网络驱动器导致的 2~4 秒卡顿迟滞。
    - 该模式通过浏览器内核底层文件选择直接唤起，毫秒级瞬时弹出，且同样完整支持递归遍历所有深层子文件夹并提取 `webkitRelativePath`。
  - **🚀 原生句柄模式 (`showDirectoryPicker`)**:
    - 配置定位缓存参数 `{ id: 'foldersnap_picker', startIn: 'desktop' }`，减少 Shell 扫描开销。
    - 点击时即时呈现 `⏳ 正在呼起弹窗...` 视觉反馈，并在 `localStorage` 记住用户偏好。


### 2.2 视觉与渲染设计 (Visual & UI Presentation)
- **决策**:
  - 采用 **macOS 磨砂毛玻璃窗口卡片**，配以红黄绿三色控件、面包屑导航路径、汇总指标 Badge（文件数量、总占用大小）。
  - 每个文件配备独立类型彩色徽标（代码/文档/图片/视频/表格/压缩包/其他）。
  - 支持 **双模式视图**：
    - **卡片分布视图 (Folder Cards View)**：每个子文件夹对应独立展示卡片，支持单个卡片截图/复制/下载。
    - **全景大图视图 (Panorama View)**：所有目录按树形或瀑布流聚合，便于一次性完整截取整张大图。

### 2.3 截图与导出技术路线 (Screenshot & Export Pipeline)
- **决策**:
  - 采用基于 Canvas/SVG 的成熟高分辨率渲染引擎（内置集成 `html-to-image` / `html2canvas` 稳定版 CDN + 本地纯原生 DOM 转 SVG/Canvas 兜底）。
  - 截图导出分辨率默认为 2x 高清超采样（确保 Retine 屏幕和高分屏下文字边缘锐利）。
  - 批量打包使用 `JSZip`，串行/小并发渲染并压缩，提供进度条与状态反馈，避免瞬间撑爆内存。

### 2.4 智能过滤与排序 (Filtering & Sorting)
- **决策**:
  - 默认忽略目录列表：`.git`, `.svn`, `.hg`, `.vscode`, `.idea`, `node_modules`, `dist`, `build`, `__pycache__`, `.DS_Store`, `Thumbs.db`。
  - 顶部设置全局开关「过滤系统与依赖文件 (如 .git, node_modules)」，用户随时可一键关闭以完整查看全部底层文件。
  - 支持按文件名、大小、修改时间进行正反排序。

## 3. 结果评估 (Consequences)
- **优点**:
  - 纯客户端离线运行，零后端依赖，用户隐私数据不出浏览器，安全可靠。
  - 视觉效果出众，生成的截图卡片具备极高设计感与专业度。
  - 满足大工程与深层目录遍历诉求，兼顾单张快捷下载与一键 ZIP 归档。
- **考量点**:
  - 深层或极大目录（上万个文件）可能导致单次渲染过长，需设计分片渲染与懒渲染/进度指示器以保障 UI 响应度。
