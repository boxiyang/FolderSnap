# FolderSnap Desktop (Windows 原生资源管理器长截图工具)

**FolderSnap Desktop** 是一款专为 Windows 系统量身定制的高性能桌面工具。它通过内嵌 Windows 操作系统底层的 **`IExplorerBrowser` Shell COM 控件**，在应用内部呈现 100% 系统级真实的资源管理器文件列表，支持**视图排版四模切换**、**智能列宽自适应防截断**、**长列表自动滚动无缝拼接长图**、**全自动递归批量子文件夹截图**以及**工程交付矢量元数据页眉**。

---

## ✨ 核心特性矩阵

### 1. 真实系统内核呈现 (100% Native Shell Integration)
- **操作系统级内嵌**：直接调用 Windows 系统的 `IExplorerBrowser` COM 接口，非 HTML/Webview 模拟，非第三方伪造列表；
- **真实系统生态**：完美呈现系统已关联的文件高精度真实图标、系统格式化列、文件右键菜单以及原生排列行为；
- **完全无弹出窗口**：无需反复呼出外部 `explorer.exe` 窗口，彻底解决弹窗闪烁、抢夺输入焦点与桌面杂乱问题。

### 2. 原生导航树与全窗口拖拽联动 (Dual Traversal & Sync)
- **系统原生导航窗格**：内置 Windows 经典左侧导航树，支持驱动器盘符、快捷访问与目录树自由展开/折叠，点击即时穿梭；
- **全窗体拖拽支持**：支持从外部资源管理器窗口直接将任意文件夹拖入窗体任意区域（控制卡片、工具栏或工作区），秒级识别载入；
- **双向地址同步**：无论是点击目录树、拖拽载入还是浏览选择，主路径、默认输出路径及底部状态栏均实时联动响应。

### 3. 四种原生排版视图自由切换 (Multi-View Layouts)
- **支持 4 种系统显示模式**：
  - **详细信息 (Details)**：经典列头表格（名称、修改日期、类型、大小），适合严密的代码架构与工程审计；
  - **大图标 (Icons)**：直观文件与媒体大图预览，适合素材库、设计资源及图片归档；
  - **列表 (List)**：横向紧凑多列排列，适合海量轻量级文件的快速盘点；
  - **平铺 (Tiles)**：带图标与辅助信息的瓷砖卡片排列，兼顾视觉与信息量；
- 切换视图时即刻应用生效，截图引擎自动匹配对应视图的最佳渲染与拼图策略。

### 4. 智能列宽自适应与内容防截断 (Smart Auto-Fit Columns)
- **最长文件名探测**：详细信息模式下，驱动 `SysListView32` 探测当前目录最长文件名并按需自动撑开名称列（保底 220px，上限 450px）；
- **标准比例保全**：科学固定与保全辅助列宽（修改日期 155px、文件类型 115px、文件大小 95px）；
- **根除截断瑕疵**：杜绝文件名因空间狭窄退化为省略号（`...`），杜绝列头文字被截断（如“修改E”）。

### 5. 智能长列表滚动无缝拼图 (Seamless Scroll Stitching)
- **滚动条状态感知**：精准读取视口 `SCROLLINFO` 结构，自动判断是否产生垂直滚动条；
- **步进翻页与行高缝合**：通过 Win32 消息自动向下翻页，精确获取文件项系统行高，在内存中动态剔除重复列头与滚动条杂边；
- **超长整图输出**：毫秒级合成一张连续、高清、像素级对齐的超长整图，轻松捕获包含数百个文件的超长目录。

### 6. 核心解耦与纯净工作区截图 (Isolated Viewport)
- **导航窗格解耦**：无论左侧原生目录树展开到多宽，截图引擎通过 Win32 层精准隔离捕获右侧纯净的文件列表视口；
- **自动消挤压**：截图前自动探测并消除由于导航栏存在而可能引发的横向内容挤压，产出的截图干净专业，杜绝系统冗余盘符杂边。

### 7. 剪贴板优先极致体验 (Clipboard-First Workflow)
- **拍照即上剪贴板**：点击“📸 仅截当前”在将高清 PNG 保存至磁盘的同时，**自动将图像数据写入系统剪贴板**；
- **一键即时贴**：免除找文件、传附件等繁琐流程，可在飞书、钉钉、企业微信、Notion、Word 或日常聊天中直接 `Ctrl + V` 粘贴送达。

### 8. 全自动递归批量截图与安全中断 (Batch Automation & Cancelable)
- **扫描深度自由配置**：
  - 全部递归（无限制穷举子目录）；
  - 仅限 1 层（直属子目录）；
  - 仅限 2 层 / 仅限 3 层（精准限制嵌套级数）；
- **智能依赖过滤**：默认内置并自动剔除 `.git`, `.svn`, `node_modules`, `bin`, `obj` 等巨量依赖与构建临时目录；
- **毫秒级安全中断**：批处理执行中，主按钮自动切换为醒目红色 **“⏹️ 停止处理 (ESC)”**，按下 `ESC` 键或点击按钮即可安全退出，已完成的图片完整安全保留在磁盘中。

### 9. 工程交付级纯矢量元数据页眉 (Vector Metadata Header)
- **专业暗色交付横幅**：可选在生成图片顶部合成 36px 现代深色页眉横幅；
- **纯 GDI+ 矢量图标绘制**：采用 GDI+ 矢量多边形绘制琥珀金文件夹图标与纯文本路径（如 `📁 /desktop/UI`），**彻底根除 Emoji 图标在特定 Windows 系统中退化为黑白方框/乱码问号的顽疾**；
- **交付凭证标注**：自动标注文件条目总数（如 `共 25 项`）与生成时间戳，是软著申报、架构审计、工程验收的专业级交付标准。

### 10. 高 DPI 自适应与精致关于对话框 (Modern UI & About)
- **高 DPI 绝对不换行**：控制面板基于流式与自适应栅格构建，在 125%、150%、200% 等高分屏缩放下，标签、按钮与下拉框均从容排布，绝不折行被挤切；
- **居中动态比例**：根据用户物理屏幕工作区动态计算最佳窗口大小并自动居中；
- **精致「关于」对话框**：状态栏内置 **“ℹ️ 关于 FolderSnap”**，提供优雅的卡片式弹窗，呈现版本信息（v1.3.0）、版权归属与核心功能；
- **专属高精度图标**：内置专属程序图标（`Resources/app_icon.ico` / `app_icon.png`）。

### 11. 单文件便携绿色，零外部依赖 (Zero Dependencies)
- 基于 Windows 自带的 C# 编译器与 .NET Framework 运行库直接编译运行；
- 产物仅 ~95KB 单一绿色可执行文件，无需安装任何 Node.js、Python、Electron 或第三方运行时。

## 🚀 快速使用指南

### 1. 运行程序
双击运行 `desktop\FolderSnapDesktop.exe`。

### 2. 选择目标目录（三种便捷方式）
- **方式 A（左侧树穿梭）**：直接在左侧原生目录树中点击任意驱动器或文件夹，右侧工作区与地址栏即时同步；
- **方式 B（直接拖拽放入）**：从外部任意文件夹拖拽放入窗体中，程序自动装载；
- **方式 C（手动浏览）**：点击顶部的“浏览...”按钮选择目录。

### 3. 配置参数与视图选项
| 配置项 | 可选项 / 默认值 | 作用说明 |
| :--- | :--- | :--- |
| **视图排版** | 详细信息 / 大图标 / 列表 / 平铺 | 切换资源管理器内嵌视口的呈现风格，适应不同归档场景 |
| **扫描深度** | 全部递归 / 1层 / 2层 / 3层 | 限制批量截图时的子目录遍历层级，避免深层结构冗余 |
| **📂 显示导航窗格** | 开启（默认开启） | 是否在工作区左侧显示系统资源管理器树状导航窗格 |
| **🏷️ 附带工程页眉** | 开启（默认开启） | 截图顶部是否附加包含矢量图标、相对路径、条目数与时间的专业横幅 |
| **↕️ 滚动拼长图** | 开启（默认开启） | 当目录内容超出窗口高度时，是否自动向下滚动并拼装成无缝长图 |
| **🛡️ 忽略依赖** | 开启（默认开启） | 批量扫描时是否自动跳过 `.git`, `node_modules`, `bin`, `obj` 等文件夹 |

### 4. 触发截图
- **📸 仅截当前**：
  - 截取当前显示的文件夹视图；
  - 自动在截图目录落盘高清 PNG 文件；
  - **自动将图片写入 Windows 剪贴板**，可直接在飞书、微信、Word 等工具中 `Ctrl + V` 粘贴。
- **⚡ 开始全自动批量截图**：
  - 自动递归遍历所选目录及其子文件夹；
  - 驱动原生视口逐一导航并执行截屏保存；
  - 任务进行时可随时按下键盘 `ESC` 或点击红色 **“⏹️ 停止处理 (ESC)”** 安全中止。

### 5. 查看输出成果
- 点击底部状态栏的 **“📁 打开截图目录”**，即可一键在系统资源管理器中打开输出文件夹查看所有成果。

## 🛠️ 编译与构建说明

应用采用系统级绿色原生架构，可直接使用 Windows 自带的 C# 编译器完成极速编译：

### 方式 1：双击批处理脚本（推荐）
直接运行项目目录下的：
```bat
desktop\build.bat
```

### 方式 2：命令行手动编译 (PowerShell / CMD)
在项目根目录下执行以下命令：
```powershell
& "C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe" `
    /target:winexe `
    /platform:x64 `
    /optimize+ `
    /out:desktop\FolderSnapDesktop.exe `
    desktop\Interop\ShellCom.cs `
    desktop\Interop\Win32Native.cs `
    desktop\Core\ExplorerHostControl.cs `
    desktop\Core\ScrollStitcher.cs `
    desktop\Core\BatchScanner.cs `
    desktop\UI\AboutDialog.cs `
    desktop\UI\MainForm.cs `
    desktop\Program.cs
```

编译完成后，将在 `desktop\` 目录下生成 `FolderSnapDesktop.exe`（单文件仅约 95KB）。

## 📂 代码架构与模块划分

```
desktop/
├── Core/
│   ├── BatchScanner.cs         # 递归子目录扫描引擎、层级深度限制与安全文件名生成
│   ├── ExplorerHostControl.cs  # IExplorerBrowser Shell COM 宿主控件与列宽自适应
│   └── ScrollStitcher.cs       # 视口滚动长图无缝缝合引擎与矢量页眉合成器
├── Interop/
│   ├── ShellCom.cs             # Windows Shell COM 接口定义 (IExplorerBrowser, IShellItem 等)
│   └── Win32Native.cs          # Win32 原生 API、消息常量、SCROLLINFO 结构体与委托
├── UI/
│   ├── AboutDialog.cs          # 现代卡片式「关于」对话框与版本特性呈现
│   └── MainForm.cs             # 现代化主窗体、高 DPI 自适应布局、拖拽与批量执行流水线
├── Resources/
│   ├── app_icon.ico            # 应用程序高精矢量图标
│   └── app_icon.png            # 关于界面预览图标
├── build.bat                   # 一键无依赖极速编译脚本
├── FolderSnapDesktop.exe       # 预编译绿色单文件可执行程序
└── README.md                   # 本说明文档
```
