# ADR-006: 移除顶部深色横幅与新增关于对话框及状态栏入口

## 状态
已采纳 (Accepted) - 2026-09-16

## 上下文
早期版本的 FolderSnap Desktop 在主界面最顶部保留了一个高度为 56px 的深色功能介绍横幅（`_topPanel`），用于展示产品名称、副标题与三项特性说明。
随着产品功能日趋成熟、用户交互重点聚焦于资源管理器浏览与快捷截图，顶部大面积黑色横幅占用了宝贵的纵向屏幕空间，且略显沉重。
用户提出：
1. 取消顶部黑色功能介绍条，使主操作区纵向上移，界面更通透、清爽；
2. 新增“关于”入口，展示应用功能、作者信息（作者：boxi）、版本号与发布日期。

## 决策

### 1. 移除顶部黑色功能横幅
- 彻底移除 `MainForm.cs` 中的 `_topPanel` 及其子控件（`_titleLabel`, `badgeLabel`, `_subTitleLabel`）；
- 窗体上边距自然对齐控制卡片，直接节省 56px 垂直高度，显著增大下方原生 Explorer 视图展示区。

### 2. 状态栏右侧关于入口 (StatusStrip Right-Aligned Link)
- 经对焦确认，不挤占第四行截图主操作按钮区，而是在窗体最底部的 `StatusStrip` 右侧添加 `_btnAbout`（`ToolStripStatusLabel`）；
- 样式为经典状态栏可点击链接风格（`IsLink = true`，带有悬浮手型指针 `Cursors.Hand`），文本为 `ℹ️ 关于 FolderSnap`；
- 始终贴靠窗口右下角（位于进度条与状态提示的右侧），克制而优雅。

### 3. 精致现代化卡片式“关于”弹窗 (AboutDialog)
- 设计独立的 `AboutDialog` 窗体（居中弹出、固定尺寸、禁止缩放）；
- 视觉排版：
  - **顶部**：展示专属精美极简图标（`app_icon.png`，64×64）；
  - **标题与版本**：`FolderSnap Desktop`，版本徽章 `v1.3.0 (Build 2026.09.16)`；
  - **作者与版权**：`作者: boxi` • `Copyright © 2026 boxi. All Rights Reserved.`；
  - **功能亮点卡片 (Feature Bento Card)**：
    - 📁 **原生 Shell 集成**：无缝内嵌 Windows 资源管理器，真实还原系统排版与图标；
    - 📜 **长列表无缝拼长图**：智能感应垂直滚动条，像素级平滑缝合全量目录条目；
    - ⚡ **全自动递归批量截屏**：支持任意深度子文件夹全自动穿梭截取，支持拖拽；
    - 🎯 **自适应无截断视口**：智能科学调制列宽，消除水平滚动条与文字省略号；
  - **底部**：现代化极简圆角“关闭”按钮。

## 效果与收益
1. **视觉通透**：去除顶部黑色横幅后，主界面空间利用率更高，焦点完全回归内容本身；
2. **信息完备**：版权、作者与版本信息规范化归拢至标准关于弹窗，专业度与仪式感显著提升。
